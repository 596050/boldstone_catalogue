# Local application bug audit — 9 November 2026

The changes address reproducible defects found by source review, existing test
suites and added regression checks. This audit does not establish that every
possible bug has been eliminated.

## Fixes

- Review startup: restored the missing local Apple Vision similarity worker;
  tested real feature extraction, ordering, missing previews and cache reuse.
- Catalogue loading: master-field records no longer require a redundant
  specifications record; gallery paths containing URI characters load correctly;
  explicitly configured private cache folders can supply retained previews.
- Shipping: absent or invalid saved US rate tables no longer break specifications
  or delivery screens. They produce an unavailable result, with no invented rate.
- Reviews: malformed version maps, request lengths and session tokens fail
  cleanly without changing saved decisions. The launcher identifies occupied
  ports instead of treating another HTTP application's error as an unused port.
- Platform status: invalid observation dates no longer crash the app; changed
  secondary photo bytes and carousel order invalidate saved verification.
  Existing checks may need one recheck because the fingerprint now includes more evidence.
- UI: incomplete costs open repairable component controls; pending saves keep
  their editor; image navigation handles empty and changed filter results.
- Read-only auditor: detects cyclic pagination even after resume, confines moved
  folder updates to the confirmed account/root, and reports malformed config.
- Search toolkit: validates profiles before atomic creation, restores the
  documented launcher, reports unavailable diagnostics as partial, removes stale
  generated tracking snippets and escapes formula text in generated CSVs.
- Squarespace content tools: preserve transparent images on white backgrounds,
  validate slugs, preserve old outputs on refresh/export failure, write outputs
  atomically, retain fractional prices and full caption links, and include the
  missing Markdown dependency.
- Request concurrency: slow/incomplete POST bodies no longer hold the catalogue
  lock; stalled bodies return a timeout without saving. Concurrent thumbnails
  share downloaded bytes even when the disk cache cannot retain them.
- Export ordering: tied carousel image positions now use the same name/ID order
  as the app. Editing package measurements immediately hides outdated US quotes;
  failed saved-package readback cannot restore an old estimate.
- Measurement parsing: sale quantities and later arrangement/fixing dimensions
  no longer replace individual sizes. Compact dimensions, small decimals,
  explicit axes and reversed ranges keep their numeric meaning. Unsupported
  units and invalid saved measurements withhold an estimate. Valid large cost
  inputs no longer crash Decimal rounding.
- Image archive/recovery: verify the recorded original format even when JPEG
  bytes have a BMP filename; reject duplicate ZIP members, invalid connector
  limits and cyclic census/preflight cursors. Fresh workers create their runtime
  directory before acquiring the conversion lock.
- Standalone relief layout lab: decimal exact fits no longer report overhang;
  SVG export handles very small accepted dimensions with finite coordinates.
- Image metadata/cache: damaged JSON and incomplete cached hashes no longer
  crash catalogue loading or certify thumbnails as originals. Header parsing
  handles core BMP dimensions and rejects truncated/zero-size headers; replacing
  a file during inspection cannot pair old dimensions with a new content hash.
  Evicted local copies retain their source records. Cache replacement uses
  unique temporary files and preserves the previous snapshot on write failure.
- Runtime setup: rejects missing handover directories and invalid read-policy
  limits, anchors private state to its original directory, reports malformed
  remembered state without overwriting it, and supplies source paths/state to
  generated cron jobs.
- Channel preparation: validates configuration under optimized Python, escapes
  JSON inside HTML, prevents overwriting prepared artifacts, and cleans partial
  writes. Spreadsheet checks inspect actual worksheet relationships and hash the
  inspected snapshot; reports cannot overwrite their source workbook. Tracking
  rejects inherited SKU names, mismatched product paths and external checkout
  links. Missing native posting helpers produce a clear blocked result.
- Real-browser delivery: edited/saved packages no longer leave phantom unsaved
  markers; a duplicate change event on blur cannot move the Save button between
  pointerdown and click, losing the first save attempt.

## Data organization

All 26 loose CSV/XLSX files from the root and Squarespace folder moved into
`data/inputs/` and `data/exports/`, grouped by catalogue, marketplace and migration.
Every original path remains a relative symbolic link.
Duplicate downloads remain separate files. All bytes were checked against both
the organization manifest and the original Git blobs; workbook relationships
contain no relative external workbook links that would break on moving.

Historical handover packs, dated output folders and reconciliation scripts stay
at their existing paths. No remote files or listings were changed.

Run `python3 scripts/check_data_layout.py` to verify the organization.
The checker also rejects incomplete manifests, missing/extra files, duplicate
entries and paths outside the organized data folders. Six regression tests
exercise these failure modes on disposable files.

nonzero for missing dependencies or failed checks. Install the application dev

layout-lab downloads. It never attaches to an existing app instance. Playwright
must be installed; `PLAYWRIGHT_MODULE` can select an external installation.

## Limits

This source checkout omits the private published catalogue, saved carrier-rate
snapshot and parts of the original handover evidence. Real catalogue launch,
authenticated image reads, live platform status and historical package integrity
cannot be certified from the included files. The complete app was exercised with
a synthetic publication and separate private runtime; carrier calculation tests
use a clearly synthetic rate fixture, never production fallback prices.

The separate historical Dropbox handover suite still has two setup errors due to
missing `blueprint/batch_index.json` / `PACKAGE_SHA256.json`. The flat migration
suite passes 26 tests and has two unavailable-evidence checks (the original ZIP
and 63 family JSON specifications). Those historical packages were preserved;
their missing evidence was not reconstructed or declared verified.

The standalone Meta supervisor also lacks its original
`meta_browser.applescript` and `meta_choose_file.applescript` helpers. No retained
copies were found. Restoring those reviewed sources and the original private
catalogue is required for real-data/native validation. The source allowlist now
retains those AppleScript files when they are restored. Mac permission, account
and publication-journal gates remain in effect.

and [Google WebP container specification](https://developers.google.com/speed/webp/docs/riff_container).
